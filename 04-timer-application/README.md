# ⏱️ Timer Application

## Scenario

You are playing a game in the office as to who can speak the longest on a given topic. You have three levels which the player can progress -  1 min, 3 min and 5 min.  So you need a simple app with a few buttons which can help you measure these intervals

## Solution
A simple countdown timer built using **SAP Build Apps**.
The application allows users to select a time limit of **1, 3, or 5 minutes** and control the countdown using Start and Reset buttons.

## ✨ Features

- Select timer duration:
  - 1 minute
  - 3 minutes
  - 5 minutes
- Start the countdown
- Automatically stops when the timer reaches `00:00`
- Reset the timer to `00:00`
- Real-time countdown display

## 🛠️ Built With

- SAP Build Apps
- Visual Logic
- Page Variables
- Formula Binding
