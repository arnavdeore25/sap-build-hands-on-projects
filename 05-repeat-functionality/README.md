# Repeat Functionality – SAP Build Apps

A simple **SAP Build Apps** project demonstrating the **Repeat** functionality using a list of objects.

## Features

- Displays multiple items using a Repeat component
- Uses a list of objects as data
- Dynamically displays item name, description, and image
- Demonstrates data binding with repeated UI elements

## Tech Used

- SAP Build Apps
- Variables
- Repeat Component
- Data Binding

## Purpose

This project was created to understand how **Repeat** works in SAP Build Apps and how a single UI layout can be reused to display multiple data records.
