# Static Student Dashboard

A small frontend-only application built using SAP Build Apps.

## 🎯 Purpose

This project was created as a hands-on exercise to practice the fundamentals of SAP Build Apps, including:

- UI components
- Layout and sizing
- Component styling
- Page creation
- Navigation
- Logic Canvas
- Events
- Desktop/Web Preview
- Mobile testing

## 📱 Pages

- Home
- Subjects
- Schedule

## 🛠️ Technology

- SAP Build Apps
- SAP BTP

## 📌 Project Type

Frontend-only / Static application

No backend, database, API, or authentication is used.
