# SAP Build Hands-on Projects

A collection of hands-on projects built while learning and practicing **SAP BTP, SAP Build Apps, and SAP Build**.

These projects are created primarily for **learning and experimentation**, with the goal of gaining practical experience with low-code application development, data integration, workflows, and SAP BTP services.

> **Note:** These projects are created for educational purposes. Any datasets used are synthetic unless explicitly stated otherwise.
