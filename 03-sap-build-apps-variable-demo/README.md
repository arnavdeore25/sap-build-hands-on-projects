# SAP Build Apps - Variable Demonstration

A simple SAP Build Apps project demonstrating the use of variables
and button-triggered data display.

## Features

- Accept user input using an Input Field
- Store input using a page variable
- Display submitted data using a Card
- Demonstrate button-triggered variable updates
- Demonstrate two-way variable binding

## Logic

User Input
    ↓
Input Field
    ↓
Button Click
    ↓
Set Page Variable
    ↓
Card displays submitted value

## Technology

- SAP Build Apps
- Visual Logic Canvas
- Page Variables
- UI Components
